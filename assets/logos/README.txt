HOW TO CHANGE YOUR IMAGES

1) Owner photo: copy your picture into this "assets" folder and name it owner.jpg
   (owner.jpeg, owner.png or owner.webp also work). A portrait photo with a visible face looks best.

2) Site logos: replace the files in assets/logos/ with your own logos, keeping the same file names
   (codelens.svg, capstone-iq.svg, codemind.svg, codeverse.svg). To use PNG files instead,
   change the "logo" path of that system inside js/data.js.

3) Versions, descriptions and links: edit js/data.js. Every page reads its content from that one file.
